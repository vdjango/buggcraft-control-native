# 玩家纪念与活动统计

本轮契约：账号页增加个人纪念页，好友与邀请操作仍在启动器。统计从启用时开始，不补造旧游戏记录。注册时间取原签名证书；已导入的好友关系继续使用同一个 friendships 所有者。

## 口径与唯一所有者

`Service::record_activity/activity` 是统计唯一所有者。presence 已鉴权的 open/refresh/close 记录“启动器在线”；placement 仅在所属节点确认有效预留或释放时记录“联机连接”。两者都不是 Minecraft 进程运行时长，不能标为游戏时长或 FPS。

服务器时间、有效租期约束相邻心跳之间的累计。多设备按账号合并，不相加；断线后不继续累计未来租期，没有有效心跳的间隔不跨越。按北京时间分日，显示最近 30 天，明细保留 400 天、累计值长期保留。会话结束最多有一个心跳间隔的测量误差，不宣称精准到秒。

同房间同代次、有效节点确认且已经是好友，才记录“同时联机的伙伴”。未知历史、删除好友以及只看过公开资料的人不伪装同玩记录；不展示好友独立在线轨迹。不以离线推断“离开了你”。伙伴名称词云使用已有真实昵称与可核验累计连接时长。

## 并发、权限与资源

统计随原事务提交，使用既有 Database 参数化查询和行锁。每次增量最多一个租期间隔，按日最多跨两天，不在主 I/O 线程执行。伙伴查询有界为 32 个；统计响应最多 30 天、64 位伙伴，不返回其他账号私有活动。`GET /api/account/memories` 仅允许当前 Cookie 账号，不接受请求方传入其他账号 ID。

统计状态是用户数据；清理仅删除过期日明细，不能清空累计值或好友关系。字段新增不改变 SDK、邀请或游戏转发协议。实际测试与部署结果追加本页，规划不冒充上线。

## 2026-11-11 本地验收与发布边界

Linux x86_64 Release/LTO 单任务构建后，CTest、20 项控制集成、11 项原生账号集成通过。覆盖多设备重叠只计一次、失效租期间隔不累计、他人账号参数不能越权、已签名好友接受后同房确认才记录、release 后伙伴租期关闭且不再累计。取消未确认预留不生成游戏记录。`companion_activity` 持有 room_id、room_epoch、lease_until，避免朋友各自换房仍被拼接为共同游玩；原表通过幂等 ADD COLUMN 增量更新。

Windows Edge 使用真实 C++ API、WebCrypto 与隔离 SMTPS，走通注册、错误密码重试、启动器设备授权及撤销、邮箱绑定、邮箱找回、新 6 位密码重新登录。纪念页真实空记录、桌面及 390 像素手机页面通过；有记录的词云视觉使用明确水印的 HTTP 测试数据，不能作为已有玩家历史。截图与日志位于相邻节点仓库 validation-artifacts/native-browser。

最新活动二进制、增量 SQL 与账号前端仅在本地完成验收，尚未替换线上原生账号版本。用户已明确服务器交由其他窗口；发布清单与包摘要见相邻节点 docs/50-网站运维/06，不据本地通过声称正式玩家已产生统计。
